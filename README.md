# 舞台换景口令沙盘

舞台换景口令的图编辑与排程沙盘：在画布上编排口令节点与前置约束（前置完成后至少等待 N 秒），系统实时重算每条口令的最早执行时间；出现环依赖时保留上次有效排程并红色高亮成环路径。支持按排程模拟执行（暂停 / 继续 / 重置），编辑导致的排程变化会同步到尚未执行的口令。开始模拟瞬间冻结本次排程快照，暂停或结束后可在「执行复盘」中只读查看每条口令的计划起止、实际起止、开始/结束偏差与状态（按时、延迟、未执行，按实际开始时间排序）及完成数、最大延迟、总工期偏差总览；模拟期间的图编辑与现场续排不改写冻结快照，重置清空复盘，图有环或未开始模拟时复盘不可用。暂停模拟时可进行「现场续排」：以当前模拟时刻为待执行口令的最早起点，锁定已完成口令的实际结束与执行中口令的实际起止，按前置等待、锁定口令的人手占用、班组容量及合并后的休息时段为待执行口令寻找最早可行空档；先展示新起止与原计划的差值，确认后仅更新本次模拟的待执行触发时间（不写入项目），重置时清空续排结果；图存在环依赖时续排禁用并展示成环路径。可在工具栏启用「开场截止」：按全部后继约束反向倒排每条口令的最晚开始时间与浮动时间，浮动最小的关键链金色高亮，截止早于最短工期时显示超期秒数并保留负浮动。选中口令或前置约束可在侧栏进行「增量预演」：输入不小于当前值的时长或等待秒数，在内存克隆图上试算（不保存），对比现行与试算的总工期、开场截止超期量及被推迟口令的传播路径，点「应用」才写入。工具栏可设置班组人数（正整数），口令侧栏可设置用人数（非负整数且不超过班组人数）；底部「班组排程」面板可维护相对零点的休息时段（起止秒数，半开区间，随项目保存，旧项目缺省为空），排程时交叠或相邻的休息时段自动合并为班组容量为零的区间，需用人的正时长口令完整避开这些区间并在允许时刻之后寻找最早可行空档（允许回填），面板同时列出休息时段、各口令排定起止与总工期。画布左上角「口令片段库」可把选中口令及其沿出边可达的全部后继口令保存为命名片段（仅收录片段内部的边，保存前预览节点与边数量，片段随项目持久化，可删除）；选中片段后在画布空白处点击即可放置副本——以原根口令为锚点整体平移，全部复制节点与边生成新 ID 并重映射端点，保留名称、时长、用人数与等待秒数，不自动连接原图，修改副本不影响片段或原图；旧项目缺省空片段库，服务端校验片段及内部节点、边 ID 唯一且边端点均在片段内，非法项目整次拒绝保存。数据持久化在本地数据卷中。

## 启动（单条命令）

```bash
docker compose up --build
```

启动完成后访问：**http://localhost:8080**（端口 `8080`）

> 依赖安装、前后端构建、示例数据初始化均随镜像构建与容器启动自动完成，无需额外步骤。
> 停止：`Ctrl+C`；后台运行可用 `docker compose up -d --build`。

## 使用说明

- **添加口令**：工具栏「＋ 添加口令」。
- **建立前置约束**：从口令节点右侧圆点拖线到目标口令；选中连线后可编辑“前置完成后至少等待秒数”。
- **编辑口令**：点击节点，在右侧栏修改名称与持续时长；每次修改都会实时重算全图最早执行时间。
- **开场截止倒排**：工具栏勾选「开场截止」并输入秒数，系统按全部后继约束反向计算每条口令的最晚开始时间与浮动时间，与最早排程共同展示（节点、侧栏、甘特图）；浮动最小的口令与约束边构成关键链并金色高亮。截止早于最短工期时，工具栏显示超期秒数，浮动如实显示为负值，便于定位无法按时完成的链路。截止设置随口令图一起持久化。
- **环依赖**：若约束构成环，顶部出现警告，排程与倒排结果回退为上次有效结果，成环的节点与连线红色高亮；「班组排程」面板同时停止输出并展示成环路径。
- **班组排程**：工具栏设置**班组人数**（正整数，旧数据缺省为 1），选中口令后在侧栏设置**用人数**（非负整数且不超过班组人数，旧数据缺省为 0），两者随口令图一起保存并校验。底部「班组排程」面板随编辑实时重算：口令的允许时刻取班组排程中全部前置（排定结束 + 约束等待）的最大值（无前置为 0）；每轮从全部前置已排定的口令中按（允许时刻, 口令 ID 字典序）选一条，放入不早于允许时刻、整个持续区间内总用人数不超容量的最早位置（允许填入已排定口令之间的空档）。占用按 [开始, 结束) 计算，零时长口令不占人。
  - **休息时段**：在「班组排程」面板可**录入 / 修改 / 删除**相对排程零点的起止秒数（半开区间 `[起点, 终点)`），随项目一起保存；服务端校验两端为有限数且 `0 ≤ 起点 < 终点`，非法输入不提交，旧项目缺省为空。面板上**交叠或相邻**的休息时段自动合并显示为一组班组容量为零的区间；需用人的正时长口令必须**完整避开**这些区间，算法在前置允许时刻之后结合已排口令的人手占用寻找**最早可行空档**（允许回填到休息前 / 口令间的空隙）。**零时长或用人数为 0 的口令不受限制**，仍可在休息时段内按前置允许时刻执行。面板同步显示休息时段、合并后的零容量区间、每条口令的排定起止与总工期。休息时段仅作用于班组排程，**最早排程、截止倒排与模拟执行不受影响**；图存在环依赖时口令排程停止输出，但休息时段仍可编辑。
- **增量预演（不保存）**：选中口令（持续时长）或前置约束（等待秒数）后，在侧栏「增量预演」中输入**不小于当前值**的试算秒数，系统在内存克隆的口令图上即时试算，并排展示现行与试算的**总工期**、**开场截止超期量**（未启用开场截止时显示“未启用”），并列出**开始时刻实际被推迟的口令及推迟秒数**；每条推迟口令附一条从改动点沿被拉紧约束传播而来的前驱路径（路径上标注各约束等待秒数），等长路径按边 ID 稳定选取一路。若改动被浮动余量完全吸收则提示无口令推迟。预演全程不触发保存：只有点击「应用」才沿现有编辑链写入并保存，「取消」直接丢弃，模拟中的已执行记录保持不变。当前图存在环时预演区提示无法试算并展示成环路径，排程回退与红色高亮不受影响。
- **模拟执行**：「开始模拟」按当前排程推进时钟；可暂停、继续、重置。模拟期间修改口令图，仅尚未执行的口令按新排程更新，执行中与已完成的口令保持原记录。
- **现场续排（暂停中）**：模拟暂停时工具栏出现「⚙ 现场续排」。点击后以当前模拟时刻为待执行口令的最早起点，锁定已完成口令的实际结束与执行中口令的实际起止（锁定口令的人手占用一并计入容量），按前置等待、班组容量及合并后的休息时段，为每条待执行口令寻找最早可行空档（选择规则与班组排程一致，允许回填）。对话框先展示每条待执行口令的**新起止与原计划的差值**及总工期对比；「确认续排」后**仅更新本次模拟的待执行触发时间**（不写入项目、不触发保存），按「继续」即按新计划执行，「重置」清空续排结果。续排生效期间工具栏显示「已续排 N 条」，甘特图中待执行口令按新触发时间绘制并以虚线框标出。图存在环依赖时续排禁用，对话框内展示成环路径。
- **执行复盘（暂停 / 结束）**：开始模拟的瞬间**冻结本次排程快照**（当时的口令结构与计划起止）；模拟暂停或全部结束后点工具栏「📋 执行复盘」即可只读查看——每条口令的**计划起止、实际起止、开始 / 结束偏差与状态（按时 / 延迟 / 未执行）**，行按**实际开始时间**排序（未执行口令排在最后）；顶部总览显示**完成数、最大延迟（最大开始正偏差）与总工期偏差**（实际总工期 − 计划总工期；暂停中标注“截至当前”）。模拟期间的图编辑与现场续排**均不改写冻结快照**（模拟开始后新增的口令不在快照内，删除的口令仍保留其计划与实际记录），因此复盘始终对照开始时的原计划；「重置」清空快照与复盘。**图有环或尚未开始模拟时复盘显示不可用**（有环时展示成环路径）。复盘**只读，不写回项目、不触发保存**。
- **视图**：拖动空白处平移，滚轮缩放；底部甘特图展示排程与执行进度，启用截止后叠加截止时刻虚线与各口令的浮动窗口。
- **口令片段库**：画布左上角浮动面板（可收起）。
  - **保存片段**：先在画布上选中一条口令，点面板「＋ 从选中口令保存片段」；面板预览将收录的**节点数与内部约束数**——系统沿该口令的出边收集全部可达后继口令，**仅收录两个端点都在片段内的边**（从片段指向外部的边不收录）。输入片段名称后回车或点「保存片段」，片段即随项目持久化；旧项目缺省空片段库。
  - **放置副本**：在面板中点选一个片段进入放置模式（画布出现蓝色虚影与提示条），**点击画布空白处**即以**原根口令为锚点整体平移**落放：全部复制节点与边生成新 ID、边端点重映射到副本节点，保留名称、时长、用人数与等待秒数（相对坐标关系不变）。落放后自动选中副本根口令；**副本不与原图自动连线**，之后修改副本既不影响片段本身，也不影响原图。放置模式下按 Esc 或再次点选该片段可取消。
  - **删除片段**：片段条目右侧「删除」仅移除库中片段，画布上已放置的副本不受影响。
  - 片段的保存、放置与删除均沿现有编辑链实时重算排程并防抖保存；服务端校验片段 ID 在库内唯一、片段内节点 / 边 ID 唯一、根口令命中片段节点且每条边端点都在片段内，校验失败时**整次拒绝保存**（HTTP 400，不覆盖原文件）。

## 本地开发（可选）

```bash
# 终端 1：后端（http://localhost:8080）
cd server && npm install && npm run dev

# 终端 2：前端（http://localhost:5173，/api 已代理到 8080）
cd client && npm install && npm run dev
```

## 技术栈与结构

- 前端：React 18 + TypeScript + Vite（SVG 图编辑器、甘特图）
- 后端：Node.js + Express + TypeScript（JSON 文件持久化，原子写入）
- 部署：多阶段 Dockerfile + Compose（命名卷 `sandbox-data` 持久化口令图）

```
├── Dockerfile            # 三阶段：前端构建 → 后端构建 → 生产运行时
├── docker-compose.yml    # 单服务，映射 8080，挂载数据卷
├── client/               # React 前端
│   └── src/
│       ├── schedule.ts       # 拓扑排程 + 截止倒排（关键链）+ 环路径检测 + 增量预演（runWhatIf）+ 班组排程（computeCrewSchedule / mergeBreaks）+ 现场续排（computeReplan）
│       ├── snippets.ts       # 口令片段：可达子图收集（reachableSubgraph）/ 保存快照（buildSnippet）/ 放置副本（instantiateSnippet，新 ID 与端点重映射）
│       ├── useSimulation.ts  # 模拟时钟（暂停/继续/重置/增量同步/现场续排触发时间/开始时冻结排程快照）
│       ├── review.ts         # 执行复盘（computeReview：冻结快照对照实际记录的偏差、状态与总览）
│       ├── ReviewPanel.tsx   # 执行复盘只读对话框（计划/实际起止与偏差、按时/延迟/未执行、总览；有环或未开始时不可用）
│       ├── GraphCanvas.tsx   # SVG 口令图编辑器（含片段放置模式：虚影预览、空白处点击落放、Esc 取消）
│       ├── SnippetPanel.tsx  # 口令片段库面板（保存预览、片段选择放置、删除）
│       ├── Timeline.tsx      # 甘特图（含续排后待执行口令的新触发时间）
│       ├── CrewPanel.tsx     # 班组排程面板（休息时段编辑、合并零容量区间、口令起止、总工期、成环提示）
│       ├── ReplanPanel.tsx   # 现场续排确认对话框（新起止与差值预览、总工期对比、成环路径）
│       └── SidePanel.tsx     # 属性编辑侧栏（含用人数）+ 增量预演（现行/试算对比、推迟路径、应用/取消）
└── server/               # Express 后端
    └── src/index.ts          # /api/project 读写（含班组人数/用人数/休息时段/口令片段库校验）+ 静态托管
```
